# Spotify Clone

A static clone of the Spotify Web Player interface, built with HTML and CSS.

**Live demo:** https://muhammadhilal072.github.io/Spotify-Clone/

## Features
- Sidebar with Home, Search, and a "Your Library" section
- Playlist cards with cover images
- Bottom player bar with playback control icons
- Custom styling in plain CSS, no frameworks

## Tech
HTML, CSS, Font Awesome (icons), Google Fonts (Montserrat)

## Note
This is a visual UI project. Buttons and links are not functional and no audio plays.

## How to run
Clone or download the repo and open `index.html` in your browser.
